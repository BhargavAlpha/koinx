## Notes from Real Interviews

- **SDE-2 L61 (2025)**: "Maximum Frequency Stack" + Linked List cycle questions (detect, find length, break cycle)
- **SDE-2 L61 (2024)**: "Maximum Sum Subsequence No Two Adjacent" + "Implement Stack using Array" with PUSH/POP/PEEK
- **SWE Intern (2024)**: Two medium-level questions - one on strings, one on recursion/backtracking
- Microsoft tests **balanced breadth** - 26% Easy, 59% Medium, 15% Hard
- Clean code, edge case handling, and communication clarity are heavily evaluated
- Follow-up questions on TC/SC optimization are standard
