## Notes from Real Interviews

- **Apple ICT4 / SDE-2 (2025, Hyderabad)**: Java/Spring Boot fundamentals asked alongside DSA
- **Phone Screen**: Expect LRU Cache, string manipulation, linked list problems
- Apple has **lowest Hard % in FAANG at 14%** - precision and code quality matter more than difficulty
- **Edge case handling** is heavily scrutinized - sloppy solutions to easy problems fail
- **Memory efficiency** is important - Apple interviewers care about memory-aware coding
- Code cleanliness and defensive programming are evaluated
- Apple expects clean, maintainable code that a teammate would want to review
