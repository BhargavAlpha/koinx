## Notes from Real Interviews

- **MTS Intern (2024)**: Binary string manipulation with 10^9 characters - TC/SC cross-questioning
- Adobe prefers **C++** but accepts Java and Python
- Strong **OOP design** foundations tested alongside DSA
- Questions on **Time and Space Complexity** are always asked as follow-ups
- Adobe-specific: Word/text processing problems (word count, string manipulation) are common
- Process: Typically 3-4 rounds - DSA, LLD, HLD (senior), Hiring Manager
- Focus areas: Arrays, Trees, DP, Graphs - in that order of frequency
