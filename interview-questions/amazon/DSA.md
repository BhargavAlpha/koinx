## Notes from Real Interviews

- **SDE-1 (2025)**: Two questions per DSA round - "Count Univalue Subtrees" + "Search in Rotated Sorted Array" with follow-ups on TC/SC
- **SDE-2 (2025)**: "Find All Anagrams in a String" with optimization to handle edge cases; "Pow(x,n)" with edge cases like 1^10000
- **SDE-1 (2024)**: DP approach discussion with dry run, TC/SC explanation expected
- **Bar Raiser**: Sometimes includes DSA questions along with Leadership Principles
- Amazon interviewers deeply probe edge cases, time/space complexity, and ask for code optimization
